# Backend — API privada

Esta pasta está reservada para o código-fonte da API privada do VetCare.

O arquivo ZIP usado para montar esta estrutura continha apenas o frontend (HTML, CSS e JavaScript). Portanto, o backend não foi copiado nem simulado aqui.

Adicione nesta pasta o projeto real da API (por exemplo, arquivos da aplicação, dependências, migrações e testes). Não envie senhas, tokens, chaves privadas ou arquivos `.env` com credenciais.
